# レビューの基準（Standards の軸に足す文書）

`review-dialogue` が上流 `code-review` を呼ぶとき、Standards の軸の「基準を書いた文書」としてこのファイルを渡す。ここに書いたものは、リポが文書化した基準と同じ扱いで、**文書化された基準の違反として指摘してよい**（baseline の smell のような判断の問題ではない）。理由・直し方・範囲の正本は [判断 0006](https://github.com/hayato1980/claude-skills/blob/main/docs/decisions/0006-config-tests-evaluate-with-the-tool.md)。ここには**何を指摘するか**だけを書く。

## 設定・IaC のテストがソースを正規表現で読んでいる

- **指摘する:** 差分で**追加または変更**された設定・IaC のテストが、対象のソースを正規表現・awk・grep で切り出して中身を確かめている。
- **指摘しない:** 差分がそのテストにも対象のコードにも触れていない既存のテスト。
- 本文には、読んでいるソースの切り出し箇所を書き、判断 0006 を参照させる。
